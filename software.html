Software

Text2Cypher

Text2Cypher-Composer (2026–present) is a Python library implementing the main approaches proposed in the literature for Text2Cypher.

 

Text2Cypher-Hub (2026–present) is a platform that collects resources for building, training, and evaluating Text2Cypher systems.

 

Biomedical IE

SchemaLink IE Engine (2026–present) is a Python library for schema-driven information extraction from biomedical text using Large Language Models. The engine is integrated into the SchemaLink schema curation environment.

 

KG Schema Curation

SchemaLink (2026–present) is a web-based environment for the graphical construction and refinement of KG schemas, including AI-assisted editing facilities.

 

Link Prediction

Link Prediction Pipeline (2025) is a pipeline for analyzing graphs using homogeneous graph representation learning methods.

 

Knowledge Graphs

RNA-KG (2024–present) is a large-scale RNA-centered Biomedical Knowledge Graph.
